# 🏠 Room / PG Management System

A simple **Java-based Room/PG Management System** developed as a college project.  
This console-based application helps manage rooms, tenants, room vacancies, rent payments, and payment history.

## ✨ Features

- 🏠 Add and view rooms
- 👤 Add and view tenants
- 🚪 Vacate rooms
- 🔍 Search rooms
- 💰 Record rent payments
- 🧾 View payment history
- 📋 Menu-driven console interface

## 🛠️ Technologies Used

- **Java**
- **OpenJDK 25**
- **Visual Studio Code**
- **ArrayList**
- **Core Java / OOP**

## 🧠 Concepts Used

- Classes and Objects
- Constructors
- Methods
- Encapsulation
- ArrayList
- Scanner
- Loops and Conditional Statements
- Switch Case
