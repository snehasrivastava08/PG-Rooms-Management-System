# Room / PG Management System

## Project Statement

The **Room / PG Management System** is a Java-based console application designed to simplify the management of rooms, tenants, and rent payments in a Paying Guest (PG) accommodation.

The system provides features to:

- Add and view rooms
- Add and view tenant details
- Search for rooms
- Vacate rooms
- Record rent payments
- View payment history

## Technology Used

- Java
- OpenJDK 25
- Visual Studio Code
- ArrayList
- Object-Oriented Programming

## Objective

The main objective of this project is to develop a simple and efficient system for managing PG rooms, tenants, and rent payments while applying basic Java and OOP concepts.
